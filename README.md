##WebMCP Enabler for Portal##

This is our Entry for DevPost WebMCP Challenge

Using this solution we can enable WebMCP for an existing Web Portal.

How to use:

Step 1: Enable WebMCP in the browser

a. Open Chrome and navigate to chrome://flags/#enable-webmcp-testing  

b. Set the flag to Enabled  

c. Relaunch Chrome to apply the changes. 


Step 2: Install the Model Context Tool Inspector Extension

a. Open Chrome and navigate to https://chromewebstore.google.com
b. Search for WebMCP - Model Context Tool Inspector widget
c. Add widget to Chrome

Step 3: Validate the Application. 


Option a: Via Website. 


a. Goto https://vinodarya.github.io/devpostMCP/. 

b. Website is not MCP Enable by default. 

c. Click on "Enable WebMCP", now the WebMCP will be enabled for the Web site. 

d. Click on "Execute Tool" on the widget. 


Option b: Run locally. 


a. Clone the Git repo to a folder. 

b. Goto the code repo folder in local. 

c. Run python3 -m http.server 8000. 

d. Open chrome browser and goto http://localhost:8080. 

e. Website is not MCP Enable by default. 

f. Click on "Enable WebMCP", now the WebMCP will be enabled for the Web site
g. Click on "Execute Tool" on the widget
